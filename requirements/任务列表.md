## 与计划的偏差

| 计划 | 实际 | 原因 |
|---|---|---|
| `better-sqlite3` | Node 24 内置 `node:sqlite` | 免去原生模块与 Windows 编译链风险 |
| `db/schema.sql` | `db/schema.ts` | 构建产物自带 schema，无需拷贝资源 |
| 模型输出覆盖标记 | 应用层文本匹配判定 | 小模型无法稳定产出标记，坏标记还会泄漏到界面 |
| `pdf-parse` 默认导出 | v2 的 `PDFParse` 类 | 包已升级到 v2，API 与 v1 不同 |
| 模型自行判断面试结束 | 轮次上限 + 手动结束 | 去掉一个不可预期的失败点 |
